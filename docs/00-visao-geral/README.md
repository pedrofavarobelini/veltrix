# PedroCore IA — Visão Geral

## Objetivo

Criar uma API/assistente pessoal de IA para testar qualidade de respostas, comportamento, contexto, prompts e múltiplos provedores.

## Decisão central

O PedroCore IA não é uma API exclusiva do Gemini. Ele é uma camada/orquestrador multi-provider.
