# Objetivo do PedroCore IA

O PedroCore IA é um assistente pessoal de inteligência artificial criado para testar respostas, contexto, qualidade de escrita, comportamento e precisão antes de evoluir para uma API usada por outros projetos.

A V1 não tem o objetivo de ser um sistema completo. O foco é validar:

- Interface de conversa
- Estrutura do backend
- Fluxo de envio e recebimento
- Organização do código
- Base para integração com IA real
