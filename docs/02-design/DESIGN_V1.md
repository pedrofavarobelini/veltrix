# Design V1

## Conceito

A interface da V1 é um chat simples e pessoal.

Não é um dashboard completo. Não é um SaaS. Não é uma central administrativa.

É uma tela para testar respostas da IA.

## Elementos principais

- Cabeçalho com nome PedroCore IA
- Seleção de modo
- Seleção de modelo
- Botão de configurações
- Área de conversa
- Campo para digitar mensagem
- Botão enviar
- Botões de ação na resposta:
  - Copiar
  - Refazer
  - Gostei
  - Não gostei

## Visual

- Tema escuro
- Fundo azul escuro/preto
- Destaque roxo/azul
- Layout centralizado
- Pouca informação na tela
