# MOC Histórico PedroCore

Hub dos documentos **históricos** do PedroCore IA.

Voltar para a entrada do grafo: [[MOC_PEDROCORE_IA]].

## O que este MOC é

Este mapa existe para que a história do projeto continue **alcançável** sem ser
confundida com o estado atual. Todo documento listado aqui descreve uma época
já superada: a fase de produto/frontend `V1`–`V5.1.9` e a primeira organização
da documentação em diretórios numerados.

## O que este MOC não é

Nada aqui é fonte canônica de estado atual. Para o estado vigente use:

- [[09_STATUS_ATUAL]] — status atual;
- [[08_CHANGELOG]] — changelog atual;
- [[03-versoes/ROADMAP]] — roadmap atual;
- [[00_MAPEAMENTO_GERAL_PEDROCORE]] — mapa completo atual;
- [[MOC_FECHAMENTOS]] — fechamentos de frente;
- [[19-encerramento-final/PEDROCORE_ENCERRAMENTO_FINAL_01]] — encerramento final do core.

## Aviso de duplicidade deliberada

Alguns temas existem em **duas** versões: um documento na raiz de `docs/` e
outro dentro de um diretório numerado. A versão da raiz é a que o
[[MOC_PEDROCORE_IA]] referencia como atual; a versão em diretório numerado é a
primeira organização, preservada como evidência.
